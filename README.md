# AI Casemix Center — RS Mandalika V9.3

Web mandiri untuk audit bukti per episode, dokumen sumber, clinical course,
evidence timeline, coding manual, review manusia, dan ekspor laporan.

Demo publik berisi data sintetis dan hanya dapat dibaca. Ruang kerja perangkat
menggunakan IndexedDB pada browser ini. Data dan dokumen tidak dikirim ke server;
tidak ada sinkronisasi cloud atau akun bersama. Berpindah perangkat/browser
tidak memindahkan data. Menghapus data situs menghapus ruang kerja perangkat.

PDF disimpan untuk peninjauan manual. Ekstraksi PDF, OCR, model AI generatif,
grouper resmi dan BPJS belum terhubung. Diagnosis dan ICD merupakan input manual.
Keputusan klinis dan coding tetap memerlukan manusia.

Ini adalah implementasi mandiri. Repository awal commit 28b336d tidak tersedia
untuk akun GitHub aktif; integrasi dan 544 regresi asli belum terverifikasi.
Branch develop dan stash V9.2 tidak disentuh.
